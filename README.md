# Portfolio

My personal portfolio — a single site that presents the projects I have built,
with a page for each one: what it does, how it works, screenshots and a link to
the live app or the source.

**Live:** https://alon-shorer.vercel.app

Currently featured: **Teams FC**, **Football Position Classifier** and
**College Management System**.

Built with Next.js, TypeScript and Tailwind CSS, statically generated and
deployed on Vercel.
